## 1. 准备

- 空白U盘，至少4GB（Windows 10要至少8GB）
- 连接网络的Windows系统电脑

## 2. 下载系统

Windows 10、Windows 8、Windows 7

推荐使用微软提供的MediaCreationTool下载速度更快，现以Windows 10安装为例。

1. 运行MediaCreationTool
2. 选择为另一台电脑创建安装介质
3. 自行选择系统的语言、版本和体系结构
4. 选择ISO文件
5. 选择下载的路径之后，点击保存。稍后即可。

## 3. 刻录光盘或U盘

下载软碟通（UltraISO）刻录软件，试用版即可。

使用方法点击链接，看官方教程

或参考如下步骤：

1. 插入U盘
2. 安装软碟通
3. 右键下载的操作系统文件，使用UltraISO打开

    1. 选择继续试用
    2. 选择工具->刻录光盘映像
    3. 选择自己的U盘或光盘

注意：刻录后，U盘会被格式化。最后检查一下映像文件，选择的U盘是否正确后即可点击刻录。

## 4. 安装系统

1. 将刻录好的U盘或光盘插入要安装系统的电脑。
2. 根据自己电脑型号或主板的型号自行网上搜索，如何进入BIOS设置BOOT。一般为Esc、F2、F7、F12、Del键。将U盘设置为启动方式后，重启电脑。
3. 重启后，电脑进入Window安装程序界面，根据安装向导执行相应的操作。

    注：其中如果没有密钥，可以点击我没有产品密钥，在系统安装好了在激活。
4. 在“你想要执行哪种类型的安装？”时，选择自定义：仅安装Windows（高级）
5. 在“你想将Windows安装在哪里？”时，可自行选择系统盘，若硬盘未使用过，先选中未分区然后点新建，选中新建的分区后点击下一步。
6. 等待系统安装完成后，在此进入BIOS设置BOOT，将刚刚装上系统的硬盘设置为第一启动项。
7. Windows 7 刚装好之后没有网卡的驱动无法上网，要提前下载好网卡驱动。

    1. Windows 7和Windows 8 安装好后，还需自行安装其他硬件驱动。
